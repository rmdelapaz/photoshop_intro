L14

Type & Hierarchy

Design is rules, not talent.

Mental model

Type has a job

  1. The BIG line: what is this?
  2. The key detail: when / where
  3. Supporting info: the extras
  4. The fine print: smallest
  • Size reads first
  • Weight: bold forward, light back
  • Space makes things feel important
The Character panel · Window ▸ Character

Three space controls

  • Leading = between lines: tighten on big titles
  • Tracking = evenly across a word: loosen small all-caps labels
  • Kerning = one specific pair of letters
TYPE T · click = point type (titles) · drag a box = paragraph type (body) · commit Ctrl/⌘Enter
Confident type in five moves

Size, weight, space

  1. Every line its own layer
  2. Assign a reading order
  3. Size boldly: a much bigger 1st line
  4. Leading on titles, tracking on small caps
  5. Two fonts max, one accent, a touch of type on a path
WATCH weak hierarchy is the #1 beginner mistake: make the main thing bigger
L15

Shapes & the Pen

Math, not pixels.

Raster vs vector

Which survives being enlarged?

  • Raster = pixels
  • No new pixels to show → soft or blocky
  • Use for: photos
  • Vector = math
  • Redrawn at any size → still crisp
  • Use for: type, logos, icons, frames
How the Pen thinks

The two-move rule

  • Straight: click, click
  • Curve: click and drag, then click and drag again
  • One anchor wherever the curve changes direction. No more.
  • Refine with Direct Selection (white arrow)
WATCH the Pen places points; it doesn't paint where you drag
Shapes & paths

Build it, combine it, reuse it

  • Shape mode: set Fill (none = red slash) and Stroke
  • Path Operations before the next shape: Combine · Subtract · Intersect
  • Path mode → Work Path → right-click: Make Selection · Fill · Stroke · Vector Mask
  • Ctrl/⌘-click a shape's thumbnail = its outline as a selection
TEST rasterize a copy, scale both 400% with Ctrl/⌘T, compare at 100%

Screen vs print

  • Screen: RGB
  • Pixel dimensions for the platform
  • Export As ▸ JPG (PNG for transparency)
  • Print: ask the printer first
  • CMYK, 300 ppi at final size
  • Bleed via Image ▸ Canvas Size
  • Save a Copy ▸ Photoshop PDF (PDF/X)
PROOF View ▸ Proof Colors Ctrl/⌘Y · neons shift most in print
