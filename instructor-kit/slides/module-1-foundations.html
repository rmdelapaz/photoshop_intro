L02

The Layer Stack & Your First Mask

Darken the sky. Only the sky.

Mental model 1

A stack of glass

  • You look straight down through the sheets
  • Higher layers win where they're opaque
  • Order is meaning: move a sheet, the picture changes
Mental model 2 · a mask is a stencil

Black hides. White reveals. Gray does a bit of both.

  • White: effect at full strength (sky)
  • Gray: partial, a soft seam
  • Black: effect hidden (land)
SUPERPOWER Mistake? Press X and paint it back. Nothing is destroyed.
Reading the Layers panel

Two thumbnails

  • ◐ = the effect
  • White/black card = the mask
  • Click the mask before you paint: it gets a highlighted border
WATCH Photo layer highlighted = you're painting on the picture.
Guided build · l02-washed-sky.jpg

Rescue the sky

  1. Save As sky-rescue-working.psd
  2. ◐ ▸ Brightness/Contrast: Brightness down (ignore the dark land)
  3. Click mask · D · X · fill black: Alt/⌥+Backspace
  4. B · X for white · big soft brush · paint the sky
  5. ~30% opacity on the seam · Save · Export sky-rescue-final.jpg
WATCH Ctrl/⌘+Backspace fills with the background color (white).
Now You

Spotlight a subject

  • Brighten → mask black → paint white over the subject
  • Second layer darkens → masked to the background
  • Going further: select a mask, Ctrl/⌘+I to invert

L03

Selections That Hold Up

Let Photoshop find the edge, then save it as a mask.

Mental model

A selection is a request. A mask is the saved answer.

  • Marching ants = temporary: "these pixels, please"
  • Mask = written down: inside white, outside black
  • Good-enough selection → mask → refine forever
MANTRA Mask it, don't erase it.
The selection toolkit

Match the tool to the subject

Select SubjectAI guesses the main subject: best first click
Object SelectionDraw a loose box; it snaps to the object
Quick SelectionPaint and it grows to matching edges
Select & MaskA whole room for hair, fur, soft edges
Guided build · l03-subject-busy-bg.jpg

Cut out a subject

  1. Save As cutout-working.psd · Select ▸ Subject
  2. Quick Selection W: paint to add, Alt/⌥-paint to subtract
  3. Select and Mask: Overlay · Refine Edge Brush · Smooth / Feather · Shift Edge slightly negative
  4. Output To: Layer Mask → OK
  5. New layer beneath (Ctrl/⌘-click New Layer) · calm fill · Save
PAYOFF Shift-click the mask: the old background is still there.
Believable edges

Kill the halo

  • Bright halo or razor edge screams "cut out"
  • Shift Edge slightly negative · a touch of Feather
  • Colored fringe? Decontaminate Colors (keeps the original, hidden)
  • Hair: Refine Edge Brush along the hairline

L04

Cleaning Up

Borrow good pixels to cover bad ones.

Mental model

Same idea, three blends

  • Clone: copies exactly (hard edges, patterns)
  • Heal: copies texture, blends color & brightness (skin, skies)
  • Content-Aware: fills a whole region automatically
MANTRA Heal to blend, clone to copy, always on a fresh layer.
Which tool for which mess?

Decide, don't memorize

Tiny spotSpot Healing Brush J: just click it
Object by hard edges, lines, patternsClone Stamp S
Object on sky, sand, grassRemove tool or Content-Aware Fill
ThenBlend & check at 100%
WHEN IN DOUBT Try the Remove tool first.
The habit that saves you

An empty retouch layer

  • Spot Healing & Remove: check Sample All Layers
  • Healing Brush & Clone Stamp: Sample: Current & Below
  • Content-Aware Fill: start from the photo layer, Output To: New Layer
WATCH "Nothing happens" = a Sample setting is still on the empty layer.
Guided build · l04-dusty-sky.jpg

Clean & export

  1. Save As cleanup-working.psd · new layer retouch
  2. Zoom 100% (Ctrl/⌘+1) · click each spot, brush just larger than it
  3. Bird & pole: Remove tool, or Content-Aware Fill
  4. Roofline: Clone Stamp, Alt/⌥-click a clean source
  5. 100% pass · Save · Export cleanup-final.jpg
