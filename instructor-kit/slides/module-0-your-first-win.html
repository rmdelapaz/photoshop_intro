L01

Fix & Export One Photo

You don't need to understand everything. You need to finish one photo.

One idea for the whole course

Tracing paper

(later) more sheets
◐ Brightness/Contrast
Your photo: never edited
  • Sheets = layers
  • Instruction-only sheets = adjustment layers
  • Original always intact = non-destructive
Steps 1–2

Protect it, then straighten it

  1. File ▸ Open → File ▸ Save As Photoshop (.psd): myphoto-working.psd
  2. C Crop: drag a corner inward to trim edges
  3. Just outside a corner → bent arrow → rotate until the grid matches the horizon
  4. Enter / Return to commit
WATCH Crop box stuck to a shape? Click Clear in the options bar.
Step 3

Add ONE adjustment layer

  • Layers panel ▸ ◐ ▸ Brightness/Contrast
  • Nudge Brightness up; a little Contrast for punch
  • A new sheet now sits above your photo
THE MAGIC MOMENT Click the eyeball off and on. The edit vanishes and returns.
Step 4

Save vs. Export

  • File ▸ Save (Ctrl/⌘+S)
  • = layered .psd, your editable master
  • File ▸ Export ▸ Export As, JPG ~80%
  • = flat .jpg you share: myphoto-final.jpg
RULE Never post the .psd. Never edit on the .jpg.
Project completion checklist

All five? Take the win.

  • Saved a working .psd before editing, and again after
  • Cropped, and the horizon looks level
  • A Brightness/Contrast layer sits above the photo
  • Its eyeball turns the edit off and on
  • Exported a .jpg; the original is untouched
After the break · on your own

Now You: your own photo

  1. Pick a photo that's too bright (or l01-too-bright.jpg)
  2. Same loop: Save As .psd → Crop → ◐ Brightness/Contrast, lower it a touch
  3. ◐ again ▸ Vibrance: push it up gently
  4. Save, export with a new name, compare with the original
GOING FURTHER Swap the two adjustment layers. Does anything change?

Open → Save .psd → Crop → Adjust → Save → Export
