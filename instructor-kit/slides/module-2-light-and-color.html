L05

The Develop Step: Camera Raw

The digital darkroom, before any local edit.

The golden rule

Global before local

  • Fix the whole image first: white balance, then overall tone
  • Only then make selective, local tweaks
  • Dodging a photo that's still orange = polishing a problem
MANTRA Develop before you decorate.
The develop pass

Wrap it, then work top to bottom

  1. Save As grade-working.psd · right-click layer name ▸ Convert to Smart Object
  2. Filter ▸ Camera Raw Filter ⇧ Ctrl/⌘ A
  3. White Balance eyedropper on a neutral → Temperature / Tint
  4. Exposure → Contrast → Highlights / Shadows → Whites / Blacks
  5. OK → a re-editable Smart Filter → Save
TIP Hold Alt/⌥ while dragging Whites / Blacks to see clipping.

L06

Curves: Precise Tone & Color

It looks like math class. It isn't. (Yet.)

A tone translator

Input across, output up

  • Diagonal = no change
  • Point up = brighter · down = darker
  • S-curve = contrast
  • Lifted black corner = faded, matte
Color with channels

Cool shadows, warm highlights

  • Channel menu: RGB ▸ Blue
  • Shadow end up (cool) · highlight end down (warm)
  • Truer teal: Red shadow end down a touch (less red = more cyan)
WATCH A few pixels of drag is already a strong grade.
Spiral back to masks

Grade one region only

  1. Second Curves layer · brighten noticeably
  2. Click the mask · D X · Alt+Backspace / ⌥+Delete = black mask
  3. X for white · soft brush over the subject
CORE LOOP Global tone + a local mask = nearly every pro grade.

L07

Smart Objects & Finishing the Grade

Edits that never commit.

The one-line definition

A photo in a sealed box

  • A Smart Object stores your pixels
  • Every edit is a re-editable instruction on the box
  • Scale down and back up: still crisp
  • Filters nest as Smart Filters with a shared mask
DEMO Normal layer vs Smart Object: 30% → 100%. Crisp or mushy?
Finish & ship

Smart Filter, mask, export

  1. Filter ▸ Sharpen ▸ Smart Sharpen or Blur ▸ Gaussian Blur
  2. Glow: filter Blending Options → Soft Light, 20–40%
  3. Paint the Smart Filters mask black where you don't want it
  4. File ▸ Save the .psd master
  5. File ▸ Export ▸ Export As ▸ JPG 80% → module2-grade-final.jpg
WATCH Heal and clone on normal layers, not on a Smart Object.
