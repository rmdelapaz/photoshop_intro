L17

Generative Fill

A tool with rules, strengths, and blind spots.

The mental model

Select the where, describe the what

  • Empty prompt → remove (fill with background)
  • Described prompt → add (a small sailboat)
  • Result: a new generative layer with its own mask
  • Three variations; Generate again for three more
WHERE Contextual Task Bar under the selection · or Edit ▸ Generative Fill
Prompts that work

Short, concrete, iterate

  • ✅ a wooden park bench
  • ❌ something nice to sit on
  • Name the object; let the scene set the light
  • Tall thing? Tall selection.
  • Missed? Tweak one or two words
  • Then refine: mask, match, heal
LIMITS hands · text · small faces · huge selections · needs internet + credits
Edit like an editor

Cleaning up vs changing the truth

  • Generative edits can change what a photo says
  • Journalism, evidence, documentary: adding or removing crosses a line
  • Content Credentials flag AI edits; disclose when honesty matters

L18

Generative Expand & Reframe

Generative Fill, aimed at empty canvas.

Crop outward

Paint past the edge

  • Crop tool (C) → Fill: Generative Expand
  • Drag the handles past the photo
  • Empty prompt = continue the scene · short prompt = steer
  • Click Generate in the task bar
WATCH A Ratio only sets the shape. You still drag outward.
Keep it believable

Expand in bites · test the horizon

  • One huge leap goes vague and repetitive
  • Expand partway, generate, repeat
  • Zoom to 100% on the seam: does the horizon jump?
  • Regenerate a thin strip; unify with a subtle grade
LAB Uncrop + reframe to 16:9, 1:1, or 4:5 · expand-working.psd
L19

Actions, Batch & Droplets

If you do it more than twice, record it.

Record "Web JPG 1200"

Do it once, press Stop

Actions ▸ Export Web ▸ Web JPG 1200
1 Convert to Profile: sRGB
2 Fit Image: 1200 × 1200 px
3 Place Embedded watermark
4 Flatten Image
5 Save As JPEG (8–10)
6 Close
  • ● record · ■ stop · ▶ play
  • Fit Image, not Image Size
  • Flatten, or no JPEG in Save As
  • Test on a portrait file first
File ▸ Automate ▸ Batch

One click, whole folder

  • Set + Action · Source = input · Destination = processed
  • Tick Override Action "Save As" Commands
  • Suppress color profile warnings · log errors to a file
  • Originals stay untouched: Batch writes copies
WATCH No override = files land where you saved while recording.
The rest of the toolkit

Image Processor · Droplet

  • Image Processor (File ▸ Scripts): web copies of a shoot, no recording
  • Droplet (File ▸ Automate ▸ Create Droplet): drag files onto it
  • Automate the boring; keep your attention for the creative
LAB Record · test · batch the practice folder · make a droplet
