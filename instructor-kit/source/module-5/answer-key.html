L14 · Type & Hierarchy

Q1
Which kind of type should you use for a big poster title?
A) Point type (a single click)
Why: point type is for short display lines. Paragraph type is a poor fit for a title: if the box is too small the overflow is hidden, and resizing the box doesn't scale the letters. So they don't behave the same (C).
Q2
What does leading control?
B) The space between lines of text
Why: leading is between lines; kerning is between one specific pair of letters (A); tracking is even spacing across a word or line. Letter thickness (C) is weight.
Q3
A small all-caps label like "TICKETS AT THE DOOR" looks cramped. What's the fix from the lesson?
C) Add positive tracking
Why: loosening tracking on small all-caps labels makes them feel deliberate and elegant. Tightening leading (B) is for big multi-line headlines.
Q4
What is the most common fix on a beginner poster?
A) Make the main line much bigger
Why: weak hierarchy is the most common beginner mistake. If the 1st and 2nd lines are close in size, the hierarchy is too weak. More fonts (B) or accents everywhere (C) scatter the eye.
Q5
How many fonts does the lesson recommend on one poster?
B) One or two
Why: one characterful display font for the title and one clean font for everything else. Create contrast through size and weight, not a "font circus."
Q6
Your text on a circular path is upside down along the bottom. What do you do?
C) Drag across the path with the Path Selection tool to flip it, then reposition
Why: this is normal behavior. The Path Selection tool flips text to the inside or the other side of the path and slides it along the curve.
Lab reference: Fix the Hierarchy

A correct result: poster-working.psd at 18 × 24 in, 150 ppi, dark background, with one type layer per line. The title (for the practice copy: SUMMER / MUSIC FESTIVAL) is dramatically larger than anything else, with tightened leading so its lines read as a unit. The date and place line is clearly second (the natural home for the single accent color, or a small "tickets" badge). Details are smaller; the fine print is smallest, in tracked all-caps. One or two fonts. At least one element (an arc or a circular badge stamp such as "EST · 2026 · LIVE") uses type on a path. A viewer names the reading order correctly at a glance.

Common wrong results and why:

  • All lines similar in size: timidity. Scale the 1st line up until it feels too big.
  • All text on one layer: the learner kept clicking inside existing text. Commit, then click empty canvas.
  • Title cut off: paragraph type in a too-small box. Retype it as point type.
  • Three to five fonts, accent on everything: variety in place of hierarchy. Back to two fonts, one accent.
  • Type on a path missing: usually the Ellipse tool was left in Shape mode, or the Type tool clicked beside the path rather than on it (wait for the wavy cursor).

L15 · Shapes & the Pen

Q1
Why does a vector shape stay crisp when you enlarge it?
B) It is stored as math (instructions) and redrawn fresh at any size
Why: a raster image is a grid of pixels, and enlarging it has no new pixels to show. A vector ("a circle of this radius here") is recomputed at the new size, from a stamp to a stadium banner.
Q2
What is the Pen's "two-move rule"?
A) Click for corners; click and drag for curves
Why: clicking drops a corner anchor; click-and-drag drops a smooth anchor and pulls out handles that shape the curve. That is about 90% of the Pen; adding, deleting, and converting points is tidying up.
Q3
Your Pen curve looks lumpy. What's the most likely cause?
C) Too many anchor points
Why: smooth curves need surprisingly few points: one wherever the curve changes direction. Also check that handles run roughly tangent to the curve.
Q4
You draw a closed shape with the Pen set to Path mode. Where does it appear?
B) As a Work Path in the Paths panel, not as a new layer
Why: Shape mode makes a shape layer; Path mode makes a path you can then turn into a selection, a filled area, a stroke, or a vector mask (right-click with the Pen active).
Q5
How do you prove a shape layer stays sharp and a rasterized copy doesn't?
A) Scale both up about 400% with Ctrl/⌘+T and compare at 100% zoom
Why: just zooming in (B) won't show it, because Photoshop displays both as screen pixels at high zoom. The difference appears when you actually resize: the shape stays razor sharp; the raster copy goes soft.
Q6
To subtract a small circle from your badge on the same shape layer, when do you choose Subtract Front Shape?
C) With the badge layer active, before drawing the second shape
Why: Path Operations are set before you draw the next shape (or hold Alt/⌥ as you start dragging to subtract). With the default New Layer setting, the second shape lands on its own layer instead.
Lab reference: Vector Elements

A correct result: in the Layers panel, shape layers (one thumbnail with a small shape badge) for: a frame (Fill: none, a few-pixel stroke in the accent color); a badge made from combined shapes on a single layer (for example a ring, from Subtract Front Shape), with the L14 type on a path around it; one custom Pen shape (mountain, soundwave, or leaf) with few anchor points and smooth curves. A Work Path in the Paths panel (or a vector mask) shows a path was reused, for example as a selection turned into a layer mask. Side by side after a 400% scale, the shape is crisp and the rasterized copy is soft. On l15-pen-practice.png, good tracings land close to the marked point counts.

Common wrong results and why:

  • Nothing in Layers after drawing: the Pen was in Path mode. Check the Paths panel, or switch to Shape.
  • A solid rectangle covering the poster: Fill wasn't set to none.
  • Badge on two layers: Path Operations chosen after drawing, or left on New Layer.
  • Lumpy, wobbly Pen shape with 30+ points: dragged like a brush or clicked everywhere. Redo with the two-move rule.
  • Both copies look identical after "the test": the learner only zoomed in instead of scaling with Ctrl/⌘+T.
  • Pixel-painted shapes: the Shape tool was in Pixels mode; the result is raster and won't scale cleanly.

L16 · Layer Styles & the Poster

Q1
What is a layer style?
C) A set of live, re-editable effects attached to the layer
Why: effects live on the layer rather than being painted into it; change the text or recolor the shape and they re-render. Nothing is baked in, so (A) is wrong.
Q2
How do you reuse the exact look of one styled layer on another?
A) Right-click its fx ▸ Copy Layer Style, then right-click the other layer ▸ Paste Layer Style
Why: reusing styles keeps the poster consistent, and consistency is what makes a design feel intentional. Merging (B) destroys the separate layers.
Q3
Which title treatment does the lesson recommend?
B) Gradient Overlay + a subtle Drop Shadow
Why: restraint beats effects. A tasteful poster usually uses a gradient and a soft shadow. Stacks of bevels and glows (A) read as amateur and dated.
Q4
You're exporting the poster for social media. Which settings are right?
A) RGB, JPG or PNG, pixel dimensions that fit the platform
Why: screens are RGB, and on screen the ppi number doesn't matter, only pixel dimensions. CMYK at 300 ppi as a PDF/X (B) is the print route.
Q5
Your printer wants 0.125 in of bleed. Photoshop has no bleed setting. How do you add it?
C) Image ▸ Canvas Size to add it on every side, then extend the background into it
Why: you build the bleed into the canvas. Keep type well inside the trim, not at the edges (B). Export As (A) has no bleed option.
Q6
After scaling a layer down, its stroke and shadow look too heavy. What fixes it?
B) Right-click the fx ▸ Scale Effects (or adjust the values by hand)
Why: transforming a layer doesn't resize its effects; they keep their pixel values. Scale Effects (also Layer ▸ Layer Style ▸ Scale Effects) resizes them to match. Image ▸ Image Size scales them only when Scale Styles is ticked.
Lab reference: Finish the Poster (Module 5 deliverable)

A correct result: the title shows an fx badge with Gradient Overlay (two tones of the accent) and a soft, low-opacity Drop Shadow that lifts it gently off the page. The badge has a Stroke and soft shadow, and the same style appears on at least one other element (pasted). The sponsor logo (l16-sponsor-logo.png or the learner's own) is a Smart Object; a hero image (l16-hero-stage.jpg or the learner's Module 4 composite) sits behind the type as a Smart Object via Place Embedded. No layer carries more than two or three effects. Margins are even; the hierarchy from L14 still reads at a squint. The layered .psd is intact and a screen JPG has been exported. (Homework print version: canvas enlarged by the bleed on every side with the background extended, type inside the trim, CMYK conversion on a copy or via the printer's PDF/X preset, saved with File ▸ Save a Copy as Photoshop PDF.)

Common wrong results and why:

  • Hard, black, far-offset shadow: default-ish values pushed up. Lower opacity, reduce distance, raise size a little.
  • Bevel, glow, stroke, and shadow on everything: effect enthusiasm. Remove until each remaining effect has a job.
  • Soft, jaggy logo: pasted as pixels and scaled up. Re-place it with File ▸ Place Embedded as a Smart Object.
  • Inconsistent badges: each styled by hand. Copy/Paste Layer Style.
  • Hero image hides the type: layer order. The photo goes at the bottom, above the background only.
  • Poster exported in CMYK for social, or colors look dull online: the print route was used for screen. Screen = RGB JPG.
  • Only a flattened file exists: the master was flattened. Reinforce: the .psd is the master, always.
