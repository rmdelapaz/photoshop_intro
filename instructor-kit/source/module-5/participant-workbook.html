L14

Type & Hierarchy

45 min
By the end you can
  • Set and edit text with the Type tool (point type vs paragraph type)
  • Build a clear hierarchy with size, weight, and spacing
  • Control tracking, kerning, and leading in the Character panel
  • Curve text with type on a path
Key ideas
  • Type has a job: grab attention, give the key detail, or be the fine print. Size and space each line to its job.
  • Size reads first. Weight: bold pulls forward, light recedes. Space: room around a line makes it feel important.
  • Point type (single click) for short display lines. Paragraph type (click and drag a box) for text that wraps.
  • Two fonts, maximum. One accent color on the most important thing.
TermWhat it spacesReach for it when…
LeadingBetween lines of textA headline's lines drift apart or crash together
TrackingEvenly across a run of lettersA small all-caps label needs to breathe
KerningBetween one specific pairTwo big display letters look awkwardly gapped
Worked example: starting the poster
  1. File ▸ New: 18 × 24 inches at 150 ppi, dark background. Save as poster-working.psd.
  2. Type tool (T): click once, type the event name. Commit with Ctrl/⌘+Enter, Esc, or the ✓. Click an empty spot for each other line (clicking existing text edits it).
  3. Size by reading order: title boldly biggest, then date/place, details, fine print.
  4. Window ▸ Character: tighten the title's leading; add tracking (for example +120) to small all-caps labels.
  5. Type on a path: Ellipse tool in Path mode, drag a circle, hover the Type tool until the cursor shows a wavy line, click and type. Drag with Path Selection to slide or flip it.

L15

Shapes & the Pen

45 min
By the end you can
  • Explain vector vs raster, and why vectors never pixelate
  • Draw and combine shape layers
  • Use the Pen for clean straight and curved paths
  • Turn paths into shapes, selections, or masks
Key ideas
  • Raster (a photo) is a grid of pixels: enlarge it and it goes soft or blocky. Vector is stored as math, redrawn crisp at any size. Type is vector too.
  • Use vector for type, logos, icons, frames, badges; raster for photos.
  • The two-move rule: straight line = click, click. Curve = click and drag, then click and drag again.
  • Fewer points, smoother curves: one anchor wherever the curve changes direction, no more.
  • Modes matter: Shape mode makes a shape layer; Path mode makes a Work Path in the Paths panel.
Worked example: frame, badge, custom shape
  1. Frame: Rectangle tool, Shape mode. Fill: none (white box with a red slash). Stroke: a few pixels, accent color.
  2. Badge: draw an Ellipse shape. With that layer active, pick Path Operations ▸ Combine Shapes / Subtract Front Shape / Intersect Shape Areas before drawing the next shape (or hold Shift to add, Alt/⌥ to subtract as you start dragging).
  3. Pen shape: Pen in Shape mode. Click for corners, click-and-drag for curves. Refine with the Direct Selection tool (white arrow).
  4. Path triple duty: Pen in Path mode, draw a closed path (a Work Path). Right-click it: Make Selection, Fill Path, Stroke Path, Create Vector Mask. Make Selection → Add Layer Mask.
  5. Scale test: duplicate a small shape, right-click the copy ▸ Rasterize Layer, scale both about 400% with Ctrl/⌘+T, compare at 100%.

L16

Layer Styles & the Poster

58 min
By the end you can
  • Apply layer styles (Drop Shadow, Stroke, Gradient Overlay) as live effects
  • Copy and paste styles across layers
  • Use Smart Objects for logos and repeated graphics
  • Assemble a poster and export for print vs screen
Key ideas
  • A layer style lives on the layer as a live "fx": edit the text or recolor the shape and the effects update. Same non-destructive idea as adjustment layers and Smart Filters (Module 2).
  • Restraint wins. A gradient and a soft shadow is usually enough; two or three effects per layer at most. Heavy bevels and glows read as amateur fast.
  • Open Layer Style by double-clicking a layer to the right of its name. Tick an effect to enable it; click its name to see its controls.
  • Keep your layered .psd as the master. Always.
DestinationColor modeResolutionFormat
PrintCMYK (ask the printer)300 ppi at final sizePDF (PDF/X, per the printer) or TIFF
Screen / socialRGBPixel dimensions that fit the platform (ppi doesn't matter on screen)JPG or PNG
Worked example: polish and export
  1. Title: Layer Style ▸ Gradient Overlay (two tones of the accent) + Drop Shadow (low opacity, small distance, moderate size).
  2. Badge: Stroke + soft Drop Shadow. Right-click its fx ▸ Copy Layer Style; right-click another layer ▸ Paste Layer Style.
  3. Smart Objects: File ▸ Place Embedded brings a logo or photo in as a Smart Object. Put a hero image behind the type.
  4. Assemble: Move tool with smart guides; even margins; squint.
  5. Screen: File ▸ Export ▸ Export As ▸ JPG (PNG if you need transparency).
  6. Print: get the printer's spec sheet → Image ▸ Canvas Size to add the bleed on every side (often 0.125 in / 3 mm), extend the background, keep type well inside the trim → Edit ▸ Convert to Profile on a copy (or let a PDF/X preset convert) → File ▸ Save a Copy as Photoshop PDF with the printer's preset.

Watch out

Scaled a layer and now the stroke looks too thin? Effects keep their pixel values when you transform. Right-click the fx ▸ Scale Effects. Print looks different from your screen? Soft-proof with View ▸ Proof Setup and View ▸ Proof Colors (Ctrl/⌘+Y), and confirm with the printer.

Notes

Module 5 Summary

  • Hierarchy is a planned reading order built with size, weight, and space. Leading, tracking, and kerning are your spacing controls.
  • Vector is math and stays crisp; use it for everything that isn't a photo. A path can become a shape, a selection, or a mask.
  • Layer styles are live effects; two is usually plenty. Copy and paste them for consistency.
  • Export RGB/JPG for screen and CMYK/PDF at 300 ppi for print; keep the .psd master.
