Module 5 — Design & Type

How to teach the three lessons that take learners from photo editing into design: a clear type hierarchy, crisp vector shapes and the Pen, and a polished poster finished with layer styles and exported correctly for screen and print. This module completes the Practitioner tier.

3 lessons 3 h session incl. break Lessons L14–L16 Level Practitioner Maps to Session 6

How to Use This Guide

  • Same rhythm as every module: Frame → Demo → Lab → Check. All three lessons build one file, poster-working.psd, from blank canvas to exported poster.
  • This is a mindset shift. Modules 0–4 were raster photo work; this module is design and vector. Name the shift out loud, and lean on the lesson's promise: design is a set of rules, not a talent.
  • Teal = hands-on, amber = watch-outs. In Module 5 the watch-outs are taste traps (timid titles, too many fonts, too many effects) and one real tool hurdle: the Pen.
  • Shortcuts are given as Windows / Mac. Tool letters: Type T, Pen P, Shape tools U, Path Selection / Direct Selection A, Move V.
The #1 risk of Session 6: the Pen tool wall

L15 is where confident learners suddenly feel clumsy. The Pen places anchor points; it does not draw where you drag. Teach the two-move rule (click for corners, click-and-drag for curves) before anyone touches a real shape, and hand out l15-pen-practice.png, which has the anchor points marked. Tell the room up front: "Your first curves will be lumpy. Everyone's are. The Pen rewards practice more than any tool in Photoshop."

Lesson Plans

L14

Type & Hierarchy

45 min
Objectives
  • Set and edit text with the Type tool (point type vs paragraph type)
  • Build a clear visual hierarchy with size, weight, and spacing
  • Control tracking, kerning, and leading in the Character panel
  • Curve text along a shape with type on a path
Teaching sequence + live-demo script
  1. Frame: type has a job (3m). Put l14-flat-type-before.png on screen. Ask: "What do you read first?" (Nobody agrees: that's the problem.) Say: "Every line has a job: grab attention, give the key detail, or be the fine print. Three tools do almost all the work: size, weight, space. 'I have no eye for design' usually means nobody told you the rules."
  2. New poster (2m). File ▸ New, 18 × 24 inches at 150 ppi, dark background. Save as poster-working.psd. Say: "We'll build this one file all session."
  3. Get the words down (4m). Type tool (T), click once, type SUMMER. Commit with Ctrl+Enter / ⌘+Enter, Esc, or the ✓ in the options bar. Click an empty spot for each next line (MUSIC FESTIVAL, July 18 · Riverside Park, Live bands · Food trucks · All ages, TICKETS AT THE DOOR). Say: "Clicking on existing text edits it. Click empty canvas for a new layer. Single click = point type, for short display lines. Click-and-drag a box = paragraph type, for body text that wraps."
  4. Assign jobs and size boldly (3m). Say the reading order aloud: name 1st, date and place 2nd, details 3rd, fine print last. Scale the title up until it feels uncomfortably big, then a bit more. Say: "Weak hierarchy is the most common beginner mistake. If your 1st and 2nd lines are close in size, it's too weak."
  5. Character panel (2m). Window ▸ Character. Tighten leading on the two-line title so it reads as one unit; add positive tracking (for example +120) to the small all-caps label. Say: "Leading = between lines. Tracking = evenly across a word or line. Kerning = between one specific pair of letters."
  6. Type on a path (1m). Ellipse tool, mode set to Path in the options bar, drag a circle. Hover the Type tool over the path until the cursor shows a wavy line, click, type EST · 2026 · LIVE. Drag with the Path Selection tool to slide or flip it. Say: "Upside-down on the bottom of the circle? Normal. Drag across the path to flip it."
Lab: Fix the Hierarchy (24 min)

Learners build their poster text in poster-working.psd from labs/module-5/practice/l14-poster-copy.txt (or their own event), following Steps 1–4: every line its own layer, a reading order, bold sizing, deliberate leading and tracking, one accent color, and one piece of type on a path.

Definition of done (the lesson's checklist): every line is its own type layer with a clear job; the 1st line is boldly bigger; leading and tracking are set deliberately; one or two fonts and one accent color; at least one element uses type on a path.

Circulate for: all text in one layer; a title set as paragraph type in a too-small box (overflow hidden); three or more fonts; an accent color on every line.

Beginner mistakes to pre-empt
  • Timid title. The fix on most beginner posters: "make the main thing much larger."
  • Font circus. Two fonts maximum: one characterful display font for the title, one clean font for the rest. Contrast through size and weight.
  • Paragraph type for a title. If the box is too small the overflow is hidden, and resizing the box doesn't scale the letters. Use point type for display lines.
  • Typing into the wrong layer. Clicking on existing text edits it. Commit first, then click empty canvas.
  • Crowding. White space is not wasted space; it's what makes the important things feel important.
Differentiation
  • Fast learners (if time / homework): set the same text three ways changing only size and spacing (three moods, one font, no color); recreate the hierarchy of a poster or album cover they admire; curve a tagline into a full circle around a logo; set the headline in a serif, a sans, and a script and compare the personality.
  • Struggling learners: reduce to three lines (title, date/place, fine print) and one font. Get the size jump right first; spacing and type on a path can wait. If typing new layers keeps going wrong, have them press Esc after each line as a ritual.
Check for understanding (workbook self-check) + journal

Answers: Q1 A) point type; Q2 B) the space between lines; Q3 C) add positive tracking; Q4 A) make the main line much bigger; Q5 B) one or two; Q6 C) drag across the path with the Path Selection tool to flip it. Full explanations in the Answer Key. Journal prompt: Did "I have no eye for design" ever apply to you? Write down the one rule that surprised you most.

L15

Shapes & the Pen

45 min
Objectives
  • Explain vector vs raster, and why vectors never pixelate
  • Draw and combine shape layers (rectangles, ellipses, custom shapes)
  • Use the Pen tool to make clean straight and curved paths
  • Turn paths into shapes, selections, or masks
Teaching sequence + live-demo script
  1. Frame: math, not pixels (3m). Say: "A photo is a grid of colored squares. Enlarge it and there are no new squares, so edges go soft or blocky. A vector is stored as instructions: 'a circle of this radius here.' Photoshop redraws it fresh at any size. Type is vector too. Photos are raster; logos, icons, frames, badges, and type should be vector."
  2. A frame (2m). Rectangle tool (U), mode Shape. Draw a border rectangle. Options bar: Fill = none (the white box with a red slash, No Color), Stroke = a few pixels in the accent color.
  3. A badge with Path Operations (3m). Draw an Ellipse shape. With that shape layer still active, open the Path Operations menu in the options bar and choose Subtract Front Shape, then draw a smaller circle. Say: "Set the operation before drawing the next shape. Hold Shift to add or Alt/⌥ to subtract as you start dragging. On the default New Layer setting, the second shape lands on its own layer instead." Show the shape layer's thumbnail badge; double-click the thumbnail to recolor.
  4. The Pen's two-move rule (5m). Pen (P), mode Shape. On l15-pen-practice.png: trace the lightning bolt with clicks only. Say: "Straight line: click, click." Then the leaf: click-and-drag to pull out handles. Say: "Curve: click and drag, then click and drag again. That's 90% of the Pen." Nudge an anchor and a handle with the Direct Selection tool (white arrow). Say: "One anchor wherever the curve changes direction, and no more."
  5. Paths do triple duty (2m). Switch the Pen to Path mode, draw a closed path. Show it in the Paths panel as a Work Path, not a layer. With the Pen still active, right-click the path: Make Selection, Fill Path, Stroke Path, Create Vector Mask. Choose Make Selection, then Add Layer Mask. Say: "Straight back to Module 1. And for any shape layer, Ctrl/⌘-click its thumbnail to load it as a selection."
  6. The scale test (1m). Duplicate a small shape layer, right-click the copy ▸ Rasterize Layer. Scale both about 400% with Ctrl/⌘+T; view at 100%. Say: "Just zooming won't show it: Photoshop draws both as screen pixels at high zoom. The difference appears when you resize."
Lab: Vector Elements (23 min)

In poster-working.psd: a stroked frame with no fill, a badge from combined shapes (with the L14 type on a path around it), one custom Pen shape (a mountain, a soundwave, a leaf), one path reused as a selection or mask, and the scale test. Warm up on labs/module-5/practice/l15-pen-practice.png first (5 min max).

Definition of done: a vector frame with a stroke and no fill; a badge built from combined shapes; one custom Pen shape with few, clean anchor points; shape edges crisp after scaling up 400% (the rasterized copy is not); at least one path reused as a selection or mask.

Circulate for: a Pen left in Path mode when they wanted a shape (nothing appears in Layers); dozens of anchor points; frames with a solid fill covering the poster; badges on two separate layers because Path Operations was set after drawing.

Beginner mistakes to pre-empt
  • Dragging the Pen like a brush. It places points; it doesn't paint. Demonstrate the wrong way once so they recognize it.
  • Too many anchor points = lumpy curves. Also check that handles run roughly tangent to the curve.
  • Wrong mode. Shape mode makes a layer; Path mode makes a Work Path; Pixels mode is raster. Check the options bar first.
  • Rasterizing to "fix" something. Rasterizing throws away crisp-at-any-size. Only for pixel edits, and keep a vector copy.
Differentiation
  • Fast learners (if time / homework): the "Pen game" (heart, cloud, lightning bolt with as few points as possible); rebuild l15-logo-to-rebuild.png with Shape tools and Path Operations; trace a hard-edged subject (a bottle, a car) with the Pen instead of Select & Mask.
  • Struggling learners: Pen straight lines only today (the mountain range or lightning bolt: clicks only). Build the frame and badge with Shape tools, which need no Pen at all. Curves become homework with the practice sheet.
Check for understanding (workbook self-check) + journal

Answers: Q1 B) it is stored as math and redrawn at any size; Q2 A) click for corners, click-and-drag for curves; Q3 C) too many anchor points; Q4 B) a Work Path in the Paths panel; Q5 A) scale both up about 400% and compare at 100%; Q6 C) with the shape layer active, before drawing the second shape. Journal prompt: After the two-move rule, does the Pen feel less mysterious? Note the shape you found hardest to trace and why.

L16

Layer Styles & the Poster

58 min
Objectives
  • Apply layer styles (Drop Shadow, Stroke, Gradient Overlay) as live effects
  • Copy, paste, and reuse styles across layers
  • Use Smart Objects for logos and repeated graphics
  • Assemble a poster and export correctly for print vs screen
Teaching sequence + live-demo script
  1. Frame: live effects (3m). Say: "A layer style lives on a layer, not painted into it. Change the text and the shadow follows. It's the same non-destructive idea as adjustment layers and Smart Filters from Module 2, applied to effects." Then the warning: "Overdone layer styles are the fastest way to make work look dated. One or two effects usually beats five."
  2. Lift the title (4m). Double-click the title layer to the right of its name to open Layer Style. Tick Gradient Overlay, pick a two-tone version of the accent. Tick Drop Shadow (it's at the bottom of the list), click its name to see its controls: low opacity, small distance, moderate size. Edit the title text afterward to show the effects follow live.
  3. Style and reuse (3m). Give the badge a Stroke and a soft Drop Shadow. Right-click its fx ▸ Copy Layer Style; right-click another layer ▸ Paste Layer Style. Say: "Consistency is what makes a design feel intentional."
  4. Smart Objects and a hero image (3m). File ▸ Place Embedded l16-sponsor-logo.png (it comes in as a Smart Object), scale it freely. Place a hero photo (l16-hero-stage.jpg, or a learner's Module 4 composite) behind the type.
  5. Assemble (1m). Move tool with smart guides; even margins; squint. Say: "The title dominates, the accent points to the key action, nothing is crowded against the edges."
  6. Export: screen vs print (4m). Screen: File ▸ Export ▸ Export As ▸ JPG (PNG if you need transparency), RGB, pixel dimensions that fit the platform. Print: Say: "First, ask the printer for their spec sheet: CMYK profile or PDF/X preset, and bleed, often 0.125 in / 3 mm per side. Photoshop has no bleed setting, so you build it in." Show Image ▸ Canvas Size (add the bleed on every side, extend the background into it, keep type well inside the trim), Edit ▸ Convert to Profile on a copy, File ▸ Save a Copy as Photoshop PDF with the printer's preset. Mention soft-proofing: View ▸ Proof Setup and View ▸ Proof Colors (Ctrl/⌘+Y). Say: "Keep your layered .psd as the master. Always."
Lab: Finish the Poster (34 min), Module 5 deliverable

Learners complete Steps 1–4 on poster-working.psd and export a screen version (JPG). Assets: labs/module-5/practice/l16-hero-stage.jpg and l16-sponsor-logo.png, or their own Module 4 composite and graphics. The print-ready PDF is homework unless time allows.

Definition of done (the lesson's checklist): the title has a gradient and a subtle drop shadow; a consistent style is reused (copy/paste layer style); reusable graphics are Smart Objects; effects are restrained (two or three per layer at most); everything aligned with even margins; a screen JPG exported and viewed at full size.

Circulate for: hard, black, offset drop shadows; bevel-and-glow stacks; a logo that went soft because it was placed as pixels and scaled; a flattened master.

Beginner mistakes to pre-empt
  • Heavy shadow. Lower opacity, reduce distance, raise size a little. If you can clearly see the shadow as a separate object, dial it back.
  • Styles that don't scale. Transforming a layer doesn't resize its effects, so a stroke can look too thin or too heavy afterward. Right-click the fx ▸ Scale Effects (or Layer ▸ Layer Style ▸ Scale Effects). Image ▸ Image Size scales them only when Scale Styles is ticked.
  • "Print looks different." Screens are RGB and lit; print is CMYK ink on paper and can't hit every screen color. Design in RGB, soft-proof, confirm with the printer. Neons shift most.
  • Exporting at 300 ppi for Instagram. The ppi number does not matter on screen; pixel dimensions do.
Differentiation
  • Fast learners (if time / homework): restyle the poster for a different mood and watch reused styles carry the change; build a matching square social version reusing the same styles and Smart Objects; over-style one copy deliberately next to the tasteful one; save a favorite title treatment as a reusable Style in the Styles panel; produce the print-ready PDF with bleed.
  • Struggling learners: title gradient + drop shadow, one copied style, hero image behind, export JPG. That meets the core of the deliverable; Smart Object logo and print output follow as homework.
Check for understanding (workbook self-check) + journal

Answers: Q1 C) live, re-editable effects attached to the layer; Q2 A) right-click fx ▸ Copy Layer Style, then Paste Layer Style; Q3 B) Gradient Overlay + a subtle Drop Shadow; Q4 A) RGB, JPG or PNG, pixel dimensions for the platform; Q5 C) Image ▸ Canvas Size, extending the background into the bleed; Q6 B) Scale Effects. Journal prompt: How does designing (type, shapes, layout) feel different from editing photos? Which did you enjoy more, and what does that tell you about where to go next?

Poster Gallery Protocol (10 min)

  1. Each poster JPG goes full-screen for about 30 seconds (in a large room, volunteers only).
  2. The room calls out the 1st, 2nd, and 3rd thing they read. If they match the maker's intended order, the hierarchy works.
  3. One question each: "Where does the accent color send my eye?"
  4. The maker names the style they reused and one effect they removed for restraint.

Closing the Module

Module 5 wrap-up (5 min): Practitioner tier complete

Recap the arc: a planned reading order → crisp vector structure → live polish and correct export. Every learner should leave with a layered poster-working.psd and an exported screen JPG. Celebrate it: "Five modules ago you were exporting your first fixed photo. You can now retouch, composite, and design."
