Generative features need three things

Generative Fill (L17) and Generative Expand (L18) run in Adobe's cloud. You need an internet connection, to be signed in to your Adobe account, and generative credits (every Generate spends some). If they are not available today, your instructor will show you the same workflow with offline tools (the Remove tool, Content-Aware Fill, and Crop with Fill: Content-Aware Fill). The thinking is identical, so nothing you learn is wasted.

L17

Generative Fill

50 min
By the end you can
  • Remove an object by selecting it and generating with an empty prompt
  • Add new content by selecting an area and describing what belongs there
  • Work with generative layers and cycle through variations
  • Write prompts that work, and know Generative Fill's limits
Key ideas
  • Select, then describe. The selection is the where; the prompt is the what.
  • Empty prompt = remove. Photoshop fills the selection with plausible background (a smarter cousin of Content-Aware Fill from Module 1).
  • Described prompt = add. Photoshop generates the object to fit the scene's light and perspective.
  • Every result lands on a new generative layer with its own mask, with three variations to choose from. Your original pixels are never touched.
  • The selection's size and shape steer the result: want something tall, make a tall selection.
Worked example: remove & add
  1. Open a photo with a clear distraction and some open space. Save as generative-working.psd.
  2. Remove: select the object loosely, with a little margin. In the Contextual Task Bar under the selection, click Generative Fill, leave the prompt empty, click Generate. Cycle the variations and pick the cleanest.
  3. Add: select an empty area where something could believably go. Click Generative Fill, type a short, concrete prompt (a small sailboat), click Generate. Keep one variation, or Generate again for three more.
  4. Refine: it is a normal layer with a mask, so mask a rough edge (Module 1), match light and color with clipped adjustments (Module 4), heal a small artifact (Module 3).

No task bar? Turn it on with Window ▸ Contextual Task Bar, or use Edit ▸ Generative Fill instead.

Watch out
  • Grayed out? You probably need a current Photoshop, internet, and to be signed in. It uses generative credits.
  • Blurry or low-detail result? The selection was very large. Generate in smaller pieces, or just regenerate; quality varies between runs.
  • Fine detail (hands, text, small faces) can come out wrong. Zoom in and check.
Recipe card: Generative Fill
  1. Select the area (loose, with margin), then click Generative Fill in the task bar
  2. Remove: empty prompt → Generate
  3. Add: short concrete prompt → Generate
  4. Cycle the three variations; regenerate if needed
  5. Refine on its generative layer (mask, match, heal)

Mantra: select the where, describe the what, then finish with craft.

A note on honesty

Generative edits can change what a photo says, not just how it looks. For journalism, evidence, or documentary work, adding or removing content crosses a line. Adobe embeds Content Credentials to flag AI edits. Use the power thoughtfully, and be transparent when it matters.

L18

Generative Expand & Reframe

45 min
By the end you can
  • Extend the canvas with the Crop tool and fill the new space generatively
  • Uncrop a too-tight photo to give a subject room to breathe
  • Reframe a photo to a new aspect ratio for print, web, or social
  • Guide the fill with an optional prompt and keep the seam invisible
Key ideas
  • Expand is Generative Fill aimed at empty canvas around your photo. Same generative layer, same variations, same optional prompt.
  • The Crop tool can crop outward. Set Fill: Generative Expand in the options bar, drag the handles past the photo, then Generate.
  • A Ratio only sets the shape. Photoshop first fits it inside the photo; you still drag outward.
  • Expand in bites. Several small expansions look far better than one huge leap.
  • The horizon test: a horizon or strong line that jumps at the seam is the fastest giveaway.
Worked example: uncrop & reframe
  1. Open a cramped photo. Save as expand-working.psd.
  2. Uncrop: Crop tool (C), set Fill: Generative Expand. Drag a handle outward past the edge. Leave the task bar prompt empty and click Generate. (Pressing Enter or the checkmark may also generate straight away with no prompt, so use the task bar when you want to type one.)
  3. Reframe: pick a Ratio (16:9 banner, 1:1 social, 4:5 feed post). Drag the handles outward until the box extends past the photo; the ratio stays locked. Generate.
  4. Guide it (optional): a short prompt steers the new area: a calm beach, more forest, open sky.
  5. Hide the seam: zoom to 100% along the join. Anything repeating or misaligned? Select that strip and regenerate just it (L17). Then a tiny clipped Curves or a whisper of the Module 4 unifying grade over the whole frame.
Your turn: Uncrop & reframe
  • ☐ The canvas was expanded past the original with Generative Expand
  • ☐ The subject now has appropriate breathing room
  • ☐ The photo reaches a useful new aspect ratio with no stretching
  • ☐ Horizons and strong lines run continuously across the seam
  • ☐ A subtle grade unifies original and generated areas

Which ratio did you choose, and where will this image be used? What did you see at 100% along the seam?

Watch out
  • Smeary or repetitive margins? You expanded too far in one go. Undo, expand a smaller amount, generate, repeat. A short prompt can help too.
  • Horizon does not line up? Cycle the variations; if none work, select a thin strip across the seam and regenerate it with Generative Fill.
  • Expand for composition and framing, not to invent whole landscapes from a postage stamp. Quality drops the farther you get from real pixels.
Recipe card: Generative Expand
  1. Crop tool (C), set Fill: Generative Expand
  2. Optionally pick a target Ratio, then drag the handles outward past the photo
  3. Empty prompt (continue) or a short prompt (steer) in the task bar → Generate
  4. Expand in bites for big changes; pick the best variation
  5. Check the seam at 100%; unify with a subtle grade

Mantra: crop outward, generate the margin, keep the horizon honest.

L19

Actions, Batch & Droplets

45 min
By the end you can
  • Record, play, and edit an Action
  • Run an Action across a folder with Batch
  • Resize and convert a whole shoot with the Image Processor
  • Turn an Action into a drag-and-drop droplet
Key ideas
  • An Action is a recording of your steps. Record once, replay forever: on one file, a folder, or as a droplet.
  • Actions live in Window ▸ Actions, inside a Set. Red dot = record, square = stop, triangle = play.
  • Record general steps. Fit Image fits the long edge for any orientation; Image Size would record a fixed width.
  • Automate the boring, keep the creative. Resizing, converting, watermarking, and exporting are for Actions; grading and retouching are for you.
  • Rule of thumb: if you do it more than twice, record it.
Worked example: record "Web JPG 1200"

Put your test images in one folder and make an empty "processed" folder beside it.

  1. Open one image. In the Actions panel, make a new Set (Export Web), then a new Action (Web JPG 1200), and click Record in the New Action dialog.
  2. Edit ▸ Convert to Profile, destination sRGB IEC61966-2.1.
  3. File ▸ Automate ▸ Fit Image, 1200 × 1200 px.
  4. File ▸ Place Embedded your watermark and position it.
  5. Layer ▸ Flatten Image (Save As only offers JPEG for a file without extra layers).
  6. File ▸ Save As JPEG (quality 8 to 10 on the 0 to 12 scale) into the processed folder, then close the file.
  7. Press Stop. Open a different image, select the Action, press Play to test.
  8. File ▸ Automate ▸ Batch: choose the Set and Action, Source = input folder, Destination = processed folder, tick Override Action "Save As" Commands. Click OK.
Your turn: Record & batch
  • ☐ An Action is recorded with clear, general steps
  • ☐ It plays correctly on a single test file
  • ☐ Batch processed an entire folder into the destination
  • ☐ Outputs are consistent (size, color, watermark)
  • ☐ Originals are untouched (batch wrote copies)
  • ☐ I made a droplet (File ▸ Automate ▸ Create Droplet) and dragged a folder onto it

Write the steps your Actions panel shows, in order. Did anything misbehave on the test file? What did you fix?

Three automation tools: which one when?
ToolWhereBest for
Image ProcessorFile ▸ ScriptsQuick "make web copies of this shoot" jobs (JPG, PSD, or TIFF), no recording needed
BatchFile ▸ AutomateAnything your Action can do, across a folder, with full control of source and destination
DropletFile ▸ Automate ▸ Create DropletAn Action saved as a little app on your desktop: drag files onto it (Photoshop must be installed; the droplet launches it)
Watch out
  • Batch broke on some files? Usually the Action recorded something too specific, or hit an unexpected file type or color mode. Re-record with general steps, and in Batch enable Suppress color profile warnings and error logging to a file.
  • Generative steps in an Action vary per run and need the cloud, so they are less predictable in a batch. Test carefully.
Recipe card: Automate
  1. Actions panel: new Set → new Action → Record
  2. Do the task once (convert, Fit Image, watermark, flatten, save), then Stop
  3. Test Play on one file; edit steps if needed
  4. File ▸ Automate ▸ Batch across a folder (set Source + Destination; tick Override Action "Save As" Commands)
  5. For handoff, Create Droplet; for quick resizes, Image Processor

Mantra: if you do it more than twice, record it.
