# Labs

All hands-on lab materials for the course, grouped by module (one module per
session). Each module folder has its own README with the exact files and steps; this
is the map.

```
labs/
├─ build_practice_files.py   regenerates every module-N/practice/ folder
├─ module-0/   S1 · Your First Win: fix & export one photo (crop, one adjustment layer, export)
├─ module-1/   S2 · Foundations: masked sky, subject cutout, spots & distraction cleanup
├─ module-2/   S3 · Light & Color: Camera Raw develop, Curves grades, Smart Objects & Smart Filters
├─ module-3/   S4 · Retouching: healing, frequency separation, dodge & burn
├─ module-4/   S5 · Compositing: clean cutout, match light & color, shadows & a unifying grade
├─ module-5/   S6 · Design & Type: type hierarchy, shapes & the Pen, layer styles, poster export
├─ module-6/   S7 · AI & Speed: Generative Fill & Expand, Actions, Batch & droplets
└─ module-7/   S8 · Capstone: plan, studio habits, present & critique
```

Each `module-N/` holds that module's lab README and a `practice/` folder of images for
its Guided Builds and Solo Variations. A few files are **instructor-only** and must not be
handed out up front:

- `module-3/instructor/l08-flaw-map-INSTRUCTOR.png`: the L08 answer map (kept outside `practice/`).
- `module-4/practice/l11-figure-cutout-reference.png`: a catch-up cutout for anyone whose
  L11 cutout fails; hand it out only to learners who have fallen behind.
- `module-7/practice/l21-backup-*.jpg`: ready-made backup briefs for learners who arrive at
  Session 8 with little built (plus `l22-mockup-wall.jpg` for the mockup).

## Practice file policy

- **Everything in `practice/` is synthetic:** generated by `build_practice_files.py`,
  not photographed and not stock. It ships with the kit and may be handed to enrolled
  learners under your license tier.
- **Never use the course website's `images/` folder** for labs or handouts. Those are
  Adobe Stock images licensed to the author for the website only; they are not
  licensed for redistribution.
- **Module 3 demos use the illustrated practice faces, never a learner's face.**
- **Learners' own photos come first.** Practice files guarantee everyone can finish
  every lab, but the course is designed around people's own pictures. The setup guide
  tells learners which photos to bring to which session.
- **Consent:** portraits for Module 3 (Session 4) must be of someone who agreed to be
  retouched and shown in class, or a self-portrait. Don't use photos of strangers, or
  of children who aren't the learner's own.
- **Work on copies.** Learners keep originals untouched and save a layered `.psd` master
  plus a flat export, exactly as the lessons teach. For the Module 6 batch lab, they
  batch a folder of **copies**, never their only originals.
- **Generative labs (Module 6)** need Photoshop 2025 or newer, a signed-in Adobe
  account, an internet connection, and generative credits. Have a no-generative
  fallback ready (Content-Aware Fill and the Remove tool from Module 1) for anyone
  whose account can't generate.

## Regenerating the practice files

From the `instructor-kit/` folder:

```bash
python3 labs/build_practice_files.py
```

This rebuilds every `labs/module-N/practice/` folder. Check the script's header for
its Python dependencies. Regenerate after editing the script, or if practice files go
missing.

**How references work:** the facilitator guide, workbook, and answer key point to
paths like `labs/module-4/practice/`, relative to the `instructor-kit/` root (where the
combined hand-out books live). Open the whole `instructor-kit/` folder to keep those
pointers valid.

Do not hand lab **reference notes** from the answer key to learners before the
corresponding lab.
