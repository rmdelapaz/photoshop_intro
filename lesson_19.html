🗂️ The Goal: One Click, Whole Folder

On the right, a folder of raw exports: different sizes, no watermark, inconsistent. On the left, the same folder after one batched Action: every image converted to sRGB, fitted to the same size, and watermarked. Drag the handle:

🧠 Mental Model: Record Once, Replay Forever

An Action is a recording of the steps you take in Photoshop. You press record, do a task once (resize, convert color, add a watermark, save), and press stop. Photoshop remembers every step. Now you can replay that whole sequence on any image with one click, or on a thousand images with Batch.

The mindset shift is the lesson: whenever you notice yourself doing the same steps to more than a couple of files, stop and record an Action instead. The five minutes you spend recording pays back the moment the second file arrives.

🧠 Automate the boring, keep the creative

Automation is for the mechanical parts: resizing, renaming, format conversion, watermarks, consistent exports. It frees your attention for the creative decisions, the grading, retouching, and composing that actually need a human. Speed on the routine buys time for the craft.

🛠️ Guided Build: Record & Batch

Put a handful of test images in one folder, and make an empty "processed" folder beside it.

Step 1: Record the Action · 8 min

  1. Open one image. In the Actions panel, make a new Set ("Export Web"), then a new Action ("Web JPG 1200") and click Record in the New Action dialog. From that moment, Photoshop records what you do.
  2. Do the task once:
    • Edit ▸ Convert to Profile, destination sRGB IEC61966-2.1.
    • File ▸ Automate ▸ Fit Image, 1200 × 1200 px. This fits the long edge to 1200 for landscape and portrait photos alike. (Image ▸ Image Size would record a fixed width, which goes wrong on portrait files.)
    • File ▸ Place Embedded your watermark and position it.
    • Layer ▸ Flatten Image. Current Photoshop only offers JPEG in Save As for a file without extra layers.
    • File ▸ Save As JPEG (quality 8 to 10 on the 0 to 12 scale) into the processed folder, then close the file.
  3. Press Stop. Every step is now saved.

Step 2: Test on one file · 3 min

  1. Open a different image, select your Action, and press Play. Watch it run the whole sequence by itself.
  2. If a step misbehaves, delete just that step and re-record it. Actions are editable.

⚠️ Record relative, not absolute

Actions can record specific values that do not fit every image. Prefer steps that work on any file (convert profile, Fit Image to a fixed long edge). Where an exact position matters, record on a typical image and test on an odd one before trusting the batch.

Step 3: Batch the whole folder · 6 min

  1. File ▸ Automate ▸ Batch. Choose your Set and Action, set Source to your input folder and Destination to the processed folder.
  2. Because your Action contains its own Save As, tick Override Action "Save As" Commands. Without it, Batch saves wherever you saved during recording instead of the Destination you chose.
  3. Click OK and watch Photoshop process every file automatically. What took minutes per image now takes seconds for the whole set. 🏆

✅ Project Completion Checklist

  • ☐ An Action is recorded with clear, general steps
  • ☐ It plays correctly on a single test file
  • ☐ Batch processed an entire folder into the destination
  • ☐ Outputs are consistent (size, color, watermark)
  • ☐ Originals are untouched (batch wrote copies)

🧰 Image Processor & Droplets

Two close cousins finish your automation toolkit:

ToolWhat it doesBest for
Image Processor
File ▸ Scripts		Resize and save a folder to JPG, PSD, or TIFF at once, optionally running an ActionQuick "make web copies of this shoot" jobs, no recording needed
Batch
File ▸ Automate		Runs any Action across a folder with full control of source and destinationAnything your Action can do, at scale
Droplet
File ▸ Automate ▸ Create Droplet		Saves an Action as a little app on your desktopDrag files onto it to process them, no Photoshop menus at all

💡 The droplet trick

Make a droplet for your most common export, and keep it on your desktop. Drop a folder of images onto it and they process right away. It is the fastest possible handoff: no need to open Photoshop yourself (the droplet launches it, so it must be installed), no menus, just drag and done.

🧗 Now You: Solo Variation

🌟 Your challenge

  1. Record a second Action for a different output (say a 2000 px print JPG) and batch the same folder to compare.
  2. Turn your favorite Action into a droplet and process a folder by dragging it on top.
  3. Use the Image Processor to make sRGB web JPGs of a shoot without recording anything, and note when it is quicker than a full Action.

Going further: add a masked Curves grade or a Generative step to an Action where it makes sense. Even some AI edits can be baked into a repeatable pipeline.

🍳 Recipe Card: Automate

Record once, run everywhere

  1. Actions panel: new Set → new Action → Record
  2. Do the task once (convert, Fit Image, watermark, flatten, save), then Stop
  3. Test Play on one file; edit steps if needed
  4. File ▸ Automate ▸ Batch across a folder (set Source + Destination; tick Override Action "Save As" Commands)
  5. For handoff, Create Droplet; for quick resizes, Image Processor

Mantra: if you do it more than twice, record it.

❓ Common Questions at This Stage

My batch broke on some files.

Usually an Action recorded something too specific, or hit an unexpected file type or color mode. Re-record with general steps, and in Batch enable "Suppress color profile warnings" and error logging to a file so one bad image does not stop the run.

Can an Action include Generative Fill?

Some generative steps can be recorded, but results vary per run and need the cloud, so they are less predictable in a batch than deterministic steps like resize and convert. Test carefully before trusting them at scale.

Actions vs scripts: what is the difference?

Actions record UI steps and are easy for anyone to make. Scripts (JavaScript) are code and can do logic Actions cannot, like "if landscape, do X." Start with Actions; reach for scripting only when you hit their ceiling.
